## Video policy

Every lesson uses one public English video player, with a 15–30 minute lesson window. Some are complete short tutorials; others are bounded excerpts from an existing longer course. YouTube `start` and `end` parameters delimit the excerpt. The original files are not cut, downloaded, or redistributed. Links to the original source and the publisher’s name are shown beside every lesson. Availability, advertising, and caption languages remain under YouTube and the publisher’s control. Russian notes are independently written supporting material, not a transcript, dub, or automatic translation.

The bounded chapters were selected using the publishers’ public chapter descriptions. A video can cover a subset of a lesson’s objectives; the companion notes and linked primary documentation provide the rest. Long-form programming sources contain older demonstrations, so the current Python, MDN, PostgreSQL, and Microsoft documentation linked within lessons remains the reference for current behavior and support.

## Questions and notes

The question bank is original authored educational material: 20 concept records per course, each used in single-answer, two-answer, and three-way matching exercises, for 60 exercises per course and 300 overall. The same concepts intentionally recur across formats. English and Russian explanations accompany every exercise. Questions were not copied from official exam banks or from the previous site.

The linked documentation includes the Python tutorial and standard-library reference, PostgreSQL’s SQL documentation, MDN’s HTML/CSS/JavaScript and Web API documentation, Cisco’s networking explainers, and Microsoft’s Windows support and administration documentation. It is linked for further reading rather than mirrored into the application.
